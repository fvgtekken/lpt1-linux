Goal:

Understand this idea:

1. A variable stores data.

Example:

let name = "Ana";

2. A function does something.

Example:

function sayHello() {
return "Hello!";
}

3. A function can receive data.

Example:

function sayHelloToUser(userName) {
return "Hello " + userName;
}

4. The value sent to the function is called an argument.

Example:

sayHelloToUser("Ana");

In this example:

userName is the parameter.
"Ana" is the argument.
