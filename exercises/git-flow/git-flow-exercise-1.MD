Obtener Rama Develop y hacer merge contra main

1 - hacer git pull (Esto te permite bajarte todas las ramas creadas, vas as ver que baja develop, que la cree yo desde github)

2 - Una vez que tengas en tu local la rama develop hacer merge contra main, asi develop obtiene todos los cambios info de la rama main.

3 -Este ejercicio no requerie pull request, cuando develop tenga todos los cambios de main hace push asi la rama remota develop tambien tiene los cambios de main y reviso.

4- Una vez que hagas el push a develop entra a github y mira por ti misma que la rama develop tiene los cambios de main! Listo este ejercicio
