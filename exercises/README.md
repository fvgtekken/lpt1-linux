# lpt1-linux

Repositorio de práctica para rendir LPI Linux Essentials (010-160).

## Objetivo
- Practicar Linux en  terminal (bash) con ejercicios cortos.
- Documentar comandos y conceptos del temario.
- Practicar Git básico (ramas, commits, etc) para trabajo colaborativo.

## Estructura
- `exercises/` — ejercicios resueltos y consignas.
- `linux-commands/` — comandos por categoría.
- `gitCommands/` — notas y comandos de Git usados en el repo.
- `info-lpt1-exam/` — material y notas sobre el examen.

## Cómo usar este repo
- Leer los comandos por tema en `linux-commands/`.
- Resolver ejercicios en `exercises/` o crear ramas nuevas desde main para resolverlos.
- Hacer cambios siempre en una rama (no en `main`) y abrir PR para revisión.

## Convenciones
- Archivos en Markdown (`.md`).
- Commits cortos y descriptivos.
