# Git Cherry-pick

## Diferencia con merge

Merge integra el historial completo de una rama; cherry-pick aplica un commit específico de otra rama en la rama actual.

## Qué es

git cherry-pick es un comando que permite aplicar un commit específico de una rama a la rama actual.

## Para qué se usa

Se usa cuando se necesita traer un cambio específico sin integrar todos los commits de una rama.
