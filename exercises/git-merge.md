# Git Merge

## Qué es git merge

git merge es un comando de Git que permite combinar el historial de dos ramas.

Integra los commits de una rama dentro de otra rama.

## Para qué se usa

Se usa para integrar el trabajo realizado en una rama dentro de otra, por ejemplo desde una rama de desarrollo hacia develop o main.

## Comandos básicos

git merge <nombre-de-rama>

Ejemplo:

git merge feature-login
