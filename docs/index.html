Linux Distributions

Linux is available in many distributions such as Ubuntu, Debian, Red Hat, and openSUSE. Each distribution uses the same Linux kernel but may differ in package management, release cycle, and default tools.

About Ubuntu

Ubuntu is a Linux distribution based on Debian. It is designed to be user-friendly and accessible, making it one of the most popular choices for beginners and professionals. Ubuntu uses the Linux kernel and adds its own tools, package management, and release cycle.

  • Easy to use
  • Popular in learning environments
  • Strong community support
  • Common in servers and cloud platforms

Why Learn Linux?

Linux is widely used in servers, cloud platforms, cybersecurity, software development, and DevOps environments. Learning Linux gives you strong technical foundations and helps you understand how modern systems work.

Files, Directories, and Paths

What is a file?

A file stores data, such as text, program code, or binary information.

What is a directory?

A directory is used to organize files inside the Linux file system. A directory can contain files and other directories.

Absolute path

An absolute path shows the complete location of a file or directory, starting from the root directory /.

  • /home/user
  • /etc
  • /home/user/Documents/notes.txt

Relative path

A relative path shows the location of a file or directory from the current working directory. It does not start with /.

  • Documents/notes.txt
  • Reports/report2018.txt

Why paths matter

Understanding files, directories, and paths is essential for navigating the Linux file system and using commands such as cd, ls, and pwd.

These concepts are essential for working with commands like cd, ls, and understanding how Linux organizes data internally.

Basic Linux Commands

These are fundamental commands required for navigating and managing a Linux system through the command line.

  • pwd – Print working directory (shows current path)
  • ls – List directory contents
  • cd – Change directory
  • mkdir – Create a new directory
  • cp – Copy files or directories
  • mv – Move or rename files
  • rm – Remove files or directories
