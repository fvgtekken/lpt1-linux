Shell y entorno

bash — Inicia el intérprete de comandos Bash.

echo — Imprime texto o el valor de variables en la salida estándar.

history — Muestra el historial de comandos ejecutados.

export — Marca una variable para que sea heredada por procesos hijos.

type — Indica cómo se interpreta un comando (builtin, alias, archivo).

Ayuda y documentación

man — Muestra el manual de un comando.

info — Muestra documentación en formato info.

locate — Busca archivos por nombre usando una base de datos.

/usr/share/doc — Directorio con documentación instalada de paquetes.
